VS CODE SETUP
=============

1. Open this folder in VS Code.
2. Keep these three files together:
   index.html
   style.css
   script.js
3. Install "Live Server" extension if you do not already have it.
4. Right-click index.html -> Open with Live Server.
5. Drag the flower downward and release.

PERSONALIZE:
Open script.js and change only:
const birthdayName = "Birthday Girl";
